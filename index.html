REVIEW & EXPORT

Prepare your preview.

Configure your conversion destination, inspect app assets, and export a playable file.

1 · Set your destination

One file. Your app. Your branding. Download a playable HTML file, then share it directly or host it yourself. Add local images, scripts, and sounds with the asset picker before export. Missing or ambiguous local assets now prevent export, protecting shared previews from broken files. Remote assets still need internet access. For projects with folders, select the asset folder to preserve relative paths. Local CSS files, their nested imports, and their static image/font dependencies are bundled during export when the files are provided. Static JavaScript module imports are bundled when all referenced files are selected. Runtime fetches, workers, non-literal dynamic imports, and cyclic module graphs still require manual verification. Hosted links are coming later.
